The installed candidate is a **local Debug opt-in**, backed by a disposable
fictional database. The unsigned Release device build preserves historical default
navigation and excludes the private investigation/new local shell. Building it is
not acceptance of the replacement product or authorization to distribute it.
[readiness.json](release/beta/readiness.json) is an explicit all-closed external
acceptance register, not executable configuration. Test results cannot open it.

## Disable and recovery design

The local runtime supports independent admission, processing, discovery and fixture
switches; real ingestion/source/analytics flags are constrained false. Pausing
admission does not block safe reads, leave/cancel, filed reviews or exact recovery.
Pausing processing preserves pending work and uses actual later notice timestamps;
resuming a bounded scheduler pass never backdates the review window. The operator
runbook records exact request/run UUID reuse and SQLSTATE-only failure handling.

For the local preview, Ctrl-C performs scoped shutdown: all fictional gates off,
only its actors' sessions revoked, records retained. The owned Supabase stack stays
running and the original stack is untouched. Hosted kill switches, alert delivery,
credential rotation and recovery must be implemented/verified on the approved
hosted environment; do not treat local fixture controls as hosted operations.

## Human acceptance script (not yet executed)

Ask two and then six consenting adults to explain, in their own words, who is in
this roster, whose goals apply, what everyone must agree to, which current data is
shared, how ties/missing results/each person's exit affect a result, what no real
money means, and their next review deadline. Have each leave voluntarily without
coaching. Repeat with a personal goal, target-free leaderboard and private community.
Do not mark comprehension passed based on automated taps or screenshots.

On an explicitly opted-in physical device, inspect VoiceOver order and labels,
large text, reduced motion, Switch Control/Voice Control, error recovery and
account switching. Keep raw source investigation screens out of any recording.
Record only categorical findings, action names, observed failures and acceptance,
not Health totals, routes, usernames, amounts or review text. No instrumentation
has been enabled, and no testers have been contacted.
