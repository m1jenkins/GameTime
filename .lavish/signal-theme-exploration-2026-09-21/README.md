# Signal theme exploration — September 21, 2026

Proposed visual directions, requested by the owner from the complete Signal mockup. This study does not adopt a new design system or change the native app, rules, accounts, hosted services or payment behavior. Robinhood inspiration was explicitly removed during the task.

Open `index.html` using `lavish-axi index.html` from this directory. The review session is [here](http://127.0.0.1:4387/session/5c13be5a468c9da2). All consumed artwork, fonts and research screenshots are local.

## Directions

- **Pace:** warm athletic editorial photography, condensed headlines and vermilion actions.
- **Rally:** aubergine, peach and yellow graphic sport, with a bespoke running shoe pictogram.
- **Fieldwork:** forest ink, paper, print illustration and a bespoke outdoor club emblem.

Design source is the owner's explicit request for alternative visual themes. The current Signal source controls fixtures and behavior; selected Mobbin screens inform composition. The existing adopted design stays unchanged. The initial recommendation is Pace with selected Rally iconography, pending owner feedback.

## Scope

Three themes × five screens: Home, Your goal, Completed result, Challenges and You. Activity can switch between saved and missing on Home/Your goal. That choice carries into the challenge row. Navigation changes every theme together for comparison. Phone content scrolls independently.

The goal is the current fictional 6.4/20 km example for September 21–27, 2026. Home promotes the running goal already present in the current mockup. Its friend invitation and step goal remain secondary. No daily series, GPS track, odds, streak or new data source was added.

The completed result is the distinct earlier September steps fixture: 52,480/50,000 for you and 61,200/60,000 for Sam; both goals met. The $20 simulated return remains a separate recorded fact. The result is not presented as the current running goal finishing.

`Full goal rules` retains the current personal running agreement. The exit disclosure links back to the complete walkthrough. Invitation and friend buttons explain their scope locally. This is a theme comparison, not a replacement for the 182-screen walkthrough.

Theme-selection buttons only select locally. The form queues one replaceable answer; Lavish's Send action delivers it. It requests another design pass, never authorizes native implementation. No answer was submitted by the agent during verification.

## Verification

- JavaScript syntax check passed.
- Browser inspected at desktop 1440×1100 and narrow 390×844; no page or visible phone horizontal overflow in checked states.
- All three goal pages render the corresponding title and full rules; all three completed result pages render confirmed earlier results. Activity control disables on completed results.
- Narrow view shows only the selected direction; missing activity displays an unknown value and next step.
- Local referenced assets checked; non-lazy images loaded. Baseline screenshot is lazy within a collapsed disclosure.
- Independent source review found a hardcoded saved value in the Challenges row after switching to Missing; corrected to use the shared state.
- Impeccable's mechanical detector ran in degraded regex mode because parser dependencies were unavailable. It flagged Fraunces as commonly used. That type choice is intentional for this proposed outdoor theme; no full computed-contrast audit is claimed.

Not performed: native implementation, physical-device accessibility review, complete migration-route acceptance or user adoption. This study is local design work only.
