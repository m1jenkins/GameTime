Rank, person, and total line up in simple rows. Use that numerical discipline for small friend groups.

Direction B / Alternative

A stronger scoreboard.

More competitive emphasis, tighter density, and deliberately bolder number shapes.

Alternative

Compelling for competition.
Less balanced for the whole app.

This version makes rank and totals the visual centerpiece. It is a credible option if GameTime should feel closer to a sports scoreboard every time you open it.

What it gainsImmediate athletic character and more participants visible on Home.
What it costsPersonal goals and calm review states have less room. The heavy number style can dominate ordinary tasks.
My recommendationUse Clubhouse as the governing layout and tone. Give it an equally finished dark appearance; keep the scoreboard’s stronger styling as an alternative, not a requirement.

A system that scales

One brand. Different jobs.

Keep the visual grammar consistent while preserving the meaning of each challenge format.

01 / Hierarchy

32,480

Performance comes first.

Use bold, tabular numbers for the main result, ordinary system type for names and instructions, and quiet supporting labels. Limit each screen to one dominant number.

02 / Identity

Orange is a signal.

Reserve it for your row, meaningful progress, and the primary action. Use darker orange for small text on white. Start from existing 8–12 point corners and thin dividers.

03 / Behavior

Home →

Keep navigation familiar.

Use the planned Home · Challenges · You shell. Home puts reviews and consent ahead of active progress. Creation and community discovery live in Challenges.

When updates stop

We couldn’t update Apple Health.Your last update is still here.Try again ↻

Proposed state example. Keep the last known value and timestamp. Missing data must never look like a confirmed miss.

Before agreement

What you’re agreeing toPeople, activity, dates, targets where relevant, simulated amount, possible outcomes, and review and exit rules.

Summarize the agreement before explicit consent, with complete rules available. Opening a link does not count as agreeing.

When a goal is met

Goal metCelebrate the athletic result once it is confirmed. Keep the result and simulated return status separate.

A fresh challenge is a deliberate choice. Avoid automatic rematches, financial confetti, and loss-recovery prompts.

What still needs refinement before implementation

The generated chart spacing is illustrative. Build charts from exact values and dates; a strict under-6:00 goal requires a time below 6:00. Use consistent system numerals, left-aligned detail headers, and a single compact simulation banner throughout. The friend mockup uses orange for all bars; the final system should reserve emphasis for your row.

Use each person’s own update status in standings, with the owner’s last-update summary shown here. Restore exact end times and timezones in details and agreement review. Add loading, empty, partial-update, pending-review, tie, and unavailable-result states. Community should show only your progress and anonymous counts; its numeric settings remain undecided.

Test compact devices, large text, light/dark appearance, contrast, VoiceOver, and reduced motion in native UI. These raster concepts cannot validate those behaviors. The next design step is a small native prototype of Home → challenge → activity, followed by comprehension testing.
