# Challenge locked in — visual exploration

Four proposed confirmation-page compositions, prepared September 22, 2026.
Open `index.html` directly, or with Lavish for annotation and queued feedback.
The study is self-contained and uses no remote fonts, scripts, or images.

- A — The starting line: athletic track illustration and a left-aligned headline.
- B — The challenge pass: a tangible card with a small offset paper stack.
- C — The signal: a centered sculptural check and soft halo.
- D — On the calendar: the saved start date becomes the illustration.

The proposed starting point is A, with C's restrained arrival treatment.
No direction is adopted by this study. No native app or product behavior changes.

Design source is the September 22 cool athletic light contract in
`docs/design/SIGNAL_UI_MIGRATION.md`, current `SignalCreationTheme.swift` and
`LiveDesignComponents.swift`. Copy follows `docs/COPY.md`'s saved-confirmation
contract. All mockups use fictional September steps / Sep 24–30 / $20 simulated
with $0 fee, matching the existing local screenshot.

`assets/current-screen.png` is copied from the pre-existing simulator capture in
`.lavish/gametime-native-live-2026-09-22/captures/create-locked-in.png`; this task
did not run or install a native build. The four concepts preserve a clear close,
Go to Home and View goal. The calendar is a decorative proposal based on the
same saved date, not a new reminder flow or timeline. Confirmations do not claim
an athletic achievement or vary with amounts.

Replay, enlarged previews and reduced motion can be inspected in the browser.
Native haptics, Dynamic Type and physical-device rendering are not demonstrated
by this HTML study. Feedback queues only on explicit form submission and asks
for mockup refinement, not implementation.
