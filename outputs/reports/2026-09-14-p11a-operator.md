## Implemented interface

- Extended `scripts/beta-operator.py` with scoped revoke, global support
  grant/revoke/report queue, suspension, own appeal/file, support appeal queue and
  independent appeal decisions. Existing scoped cases/reports/resolve/remove/close,
  status, worker and fictional publication commands remain available.
- Replaced obsolete moderator suspension with **only**
  `challenge_support_suspend_v1`. `suspend --challenge` is rejected. Global
  support never follows from a challenge grant, and no service-key fallback
  performs a human decision.
- Replaced the hard-coded retained b7 credential lookup and actor-number login
  with explicit owned-project, numeric loopback port and separate private
  administrator/human credential files. Administrator commands require
  `--administrator`; human commands reject it. Human sign-in checks the expected
  account UUID and logs out only that CLI session.
- Human mutations persist and sync one immutable, mode-0600 record in a private
  directory before authentication/HTTP. Records bind project/port, actor, RPC and
  canonical JSON bytes to the request UUID. Exact reruns use those bytes;
  changed accounts, decisions, scopes or targets fail closed. Records contain
  no token, password, key, response or case context. Concurrent first writes
  cannot replace the saved request.
- Kept the server's current scope, seven-day maximum grant duration, strict
  expiry boundary, revocation, session/account checks, independent decision
  rules, immutable audit and receipt behavior. Reinstatement never restores
  ended membership or consent. Paired global report cursors are checked before
  sign-in. Raw HTTP errors and invalid CLI values are not printed.

Administrator grant/revoke RPCs have **no request UUID or exactly-once recovery
contract**. The CLI does not invent one, automatically retry grants, or claim
that reissuing cannot add an audit row. An ambiguous administrator response needs
inspection of the exact grant and audit in the owned environment before reissue.
The [existing local operations guide](../../docs/BETA_OPERATIONS_LOCAL.md) now
covers these commands, file formats, recovery procedure and this limitation.
